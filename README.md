# HirePath — Job Application Tracker

## About the Project

HirePath is a React-based web application designed to help job seekers organize and track their job applications in one place. It aims to simplify the job search process by helping users manage applications, monitor interview progress, and track their career opportunities.

## Problem Statement

Job seekers often use spreadsheets or scattered notes to track job applications, interview schedules, and application statuses. This can make it difficult to stay organized and monitor progress.

HirePath aims to provide a centralized, user-friendly platform for managing the job search journey.

## Objectives

- Build a responsive and intuitive user interface.
- Create Login and Signup pages.
- Track job applications and their statuses.
- Organize interview details.
- Display application statistics through a dashboard.
- Practice React development and maintain professional project documentation.

## Getting Started

### Prerequisites

- Node.js
- npm
- Visual Studio Code or another code editor

### Installation

1. Clone the repository:

   `git clone YOUR_GITHUB_REPOSITORY_URL`

2. Navigate to the project directory:

   `cd hirepath`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in your terminal.
